SANKET --- Landslide Risk Prediction & Monitoring System

SANKET is a landslide risk monitoring and prediction platform designed
to help identify and communicate potential landslide risks using
environmental and location-based information.

The project provides a simple dashboard for viewing risk information,
monitoring conditions, exploring historical data, and presenting
prediction results in an easy-to-understand way.

Key Features

Risk Map --- Visual representation of landslide-risk areas.

Live Monitoring --- Dashboard view for monitoring current
conditions and risk information.

Predictions --- Presents landslide-risk prediction results.

Historical Data --- Helps analyze previously recorded risk
information.

Alerts --- Displays important risk or warning information.

Dashboard --- Central interface for accessing the major system
features.

Getting Started

Prerequisites

Make sure the following are installed:

Python 3.x

Node.js and npm

Git

Visual Studio Code

1. Clone the repository

git clone https://github.com/rishikashah-1/sanket-landslide-risk.git
cd sanket-landslide-risk

2. Backend Setup

Open a terminal in the project directory and run:

cd backend

If the project contains a Python dependency file, install the
dependencies with:

pip install -r requirements.txt

Then start the backend using the command specified by the project
configuration. For the current Python entry point, the main application
file is:

python main.py

3. Frontend Setup

Open another terminal:

cd frontend

If the frontend is configured as a Node/React application, install
dependencies:

npm install

Then start the development server:

npm run dev

If the frontend is being used as a standalone HTML/CSS/JavaScript
interface, open dashboard.html in a browser or serve the frontend
using a local development server.

How It Works

The system follows a simple workflow:

Environmental / Location Data
            ↓
     Data Processing
            ↓
   Risk Prediction / Analysis
            ↓
       Risk Classification
            ↓
 Dashboard / Map / Alerts
            ↓
       User Awareness

The system is intended to transform relevant landslide-risk information
into clear visual outputs that can support monitoring and timely
awareness.
